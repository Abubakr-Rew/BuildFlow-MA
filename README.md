# BuildFlow 🏗️

**Фото-отчёты со стройки** — мобильное приложение для малых строительных компаний Бишкека.

Прораб (foreman) отправляет ежедневный фото-отчёт с объекта за менее чем 2 минуты.
Владелец компании (owner) видит, что реально сделано сегодня — по каждому объекту.

## Скриншоты

_Запустите приложение — демо-данные уже включены._

## Архитектура

```
lib/
├── app/                  # Тема, роутер, локализация
├── core/                 # Ошибки, хранилище, утилиты, виджеты
└── features/
    ├── auth/             # Авторизация
    │   ├── data/         # FakeAuthRepository, ApiAuthRepository
    │   ├── domain/       # User, Company, AuthRepository
    │   └── presentation/ # Провайдеры, экраны
    ├── projects/         # Объекты (стройплощадки)
    ├── team/             # Команда и приглашения
    ├── reports/          # Фото-отчёты
    └── profile/          # Профиль пользователя
```

**Паттерны:**
- Feature-first + Clean Architecture (presentation → domain → data)
- Riverpod для состояния
- GoRouter с `StatefulShellRoute` для ролевой навигации
- Freezed + json_serializable для immutable моделей
- Sealed `Result<T>` для обработки ошибок без исключений

## Быстрый старт

```bash
# 1. Установите зависимости
flutter pub get

# 2. Сгенерируйте код (freezed, json_serializable)
dart run build_runner build --delete-conflicting-outputs

# 3. Сгенерируйте локализацию
flutter gen-l10n

# 4. Запустите
flutter run
```

## Переключение на реальный API

В `lib/app/app.dart` замените `FakeAuthRepository` на `ApiAuthRepository`
и аналогично для `ProjectRepository`, `TeamRepository`, `ReportRepository`.

API-контракт описан в [`docs/api-contract.md`](docs/api-contract.md).

## Дизайн для стройки

- **Крупные кнопки** — работа в перчатках
- **Высокий контраст** — яркое солнце
- **Минимум шагов** — отчёт за < 2 минуты
- **Офлайн-поддержка** — слабый интернет (черновики)
- **Язык** — русский (ARB для будущей мультиязычности)
